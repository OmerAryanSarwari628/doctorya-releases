# Doctorya Darmalton — official Windows releases

Download the installer for Windows x64 from [Releases](https://github.com/OmerAryanSarwari628/doctorya-releases/releases).

- **Offline installer:** includes the WebView2 runtime for first installations without internet.
- **Online installer:** downloads WebView2 if it is missing.
- **In-app updates:** installed versions with the updater can check from Help → Check for updates.

نسخه‌های رسمی ویندوز دوکتوریا درملتون در بخش Releases قرار می‌گیرند.
برای نصب نخست فایل setup.exe را دریافت کنید. آپدیت‌های بعدی از داخل برنامه قابل دریافت‌اند.

Updater packages are signed. `latest.json`, the updater archive and its `.sig` file are used by the app;
`SHA256SUMS.txt` lists artifact checksums. Normal activation/licensing requirements still apply.

This repository contains distribution assets and release notes only. Application source is maintained separately.
No pharmacy data, databases or private signing keys are distributed here. All application rights reserved.
